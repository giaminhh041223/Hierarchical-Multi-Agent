# Agent Orchestra

Build a local, inspectable multi-agent coordinator. Keep runtime dependencies in
the Python standard library and frontend in native HTML/CSS/JavaScript until a
measured need justifies more. Run `python -m unittest discover -s tests -v`.

Never commit credentials or `.orchestra/` runtime data. Installed clients,
available model catalogs, authenticated accounts and successful inference are
different states. Label demo output and estimated token counts explicitly.

The scheduler owns task state; model outputs are untrusted proposals. Never run
commands from model JSON, install remote skills automatically, or claim that a
prompt or Git workspace is an OS sandbox. Keep independent tasks moving when a
sibling is waiting for user input. Preserve interruption state on restart.
